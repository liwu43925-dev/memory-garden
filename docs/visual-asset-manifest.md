## 全局交付约定

- 命名：全小写 ASCII，`mg-{scene}-{layer}-{object}-{state}@{scale}.webp`；源文件另存同名 PNG。
- 建议导出：PNG 作为透明母版，WebP 作为网页交付；背景提供 WebP/AVIF；1×/2× 两档。SVG 只用于明确的线性图标，不用于仿造水彩主体。
- 坐标：所有透明物件以画布左上为 `(0,0)`；同一对象多状态必须使用完全相同画布、锚点与透明边距。
- 点击区域：由 HTML/SVG 交互层定义，插画不烘焙焦点框。视觉主体小于 44×44 CSS px 时，命中框仍至少 44×44。
- 动效：仅由真实、已确认、已归档且可映射的数据触发；不得常驻循环。减动模式直接切换终态并提供文字状态。
- 安全：任何资产均不得包含文字、UI、用户原文、对齐输入、诊断暗示、危机浪漫化符号。
- 裁切安全区为 **[实现建议]**：桌面背景四周 8%，移动背景左右 14%/上下 10%；交互物件四周透明安全边距 12%–18%。最终值需在 375/768/1024/1440 实测后确认。
