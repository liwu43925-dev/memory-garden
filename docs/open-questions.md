# Memory Garden 待确认项与实现假设

## 读取到的输入

已完整读取 PRD V4.0、`docs/prd-analysis.md` 和 `design.md`。下列项目是 PRD 未明确的服务行为或实施约束；表中的 Demo 默认仅用于无后端演示，不代表正式需求。

| ID | 待确认问题 | 可替换的低风险 Demo 假设 | 确认方 |
|---|---|---|---|
| OQ-01 | 真实身份、关系组邀请/退出、成员移除和所有权如何定义？ | 本机提供显式的演示视角切换，不声称为真实登录或权限保障 | 产品/服务端 |
| OQ-02 | 真实 API 如何强制关系组隔离、单条权限和媒体授权？ | Mock Repository 每次按 `groupId` 与视角过滤；UI 不直接访问全量数据 | 服务端/安全 |
| OQ-03 | 多人同时编辑、删除、撤回与到期归档冲突如何裁决？ | 本机单事务串行处理，冲突返回统一错误；真实裁决由 API 定义 | 服务端/产品 |
| OQ-04 | 冷静期正式时长、可配置范围、计时权威和离线到期行为是什么？ | 配置默认 60 秒；存绝对到期时间，恢复时校准 | 产品/服务端 |
| OQ-05 | AI 预处理、歧义补全、高危识别、转译的请求/响应、失败重试和审计规则是什么？ | 固定的可解释样本响应与显式 Demo 触发，不伪装真实 AI | 服务端/安全 |
| OQ-06 | 图片与音频格式、大小、时长、版权、病毒检查和上传后清理规则是什么？ | 本机预览；格式/配额限制由配置注入，未批准前不宣称正式支持范围 | 产品/服务端/法务 |
| OQ-07 | 媒体 URL 的鉴权、过期、缓存和撤权后失效方式是什么？ | Blob 存本机命名空间，撤权即从投影移除并停止播放 | 服务端/安全 |
| OQ-08 | 计划哪些字段为关键字段？时区和提醒如何与日程服务衔接？ | 只演示单问题确认，不创建真实日程或提醒 | 产品/服务端 |
| OQ-09 | 本人核验、共同纪要双方确认及多人关系组中的两位参与者如何确定？ | Demo 固定两个明确标记的演示视角；双方核验后才出现对照 | 产品/服务端 |
| OQ-10 | 单条删除后的审计保留、恢复和意象空位策略是什么？ | 即时从 Demo 视图移除并同步意象；不承诺服务端不可恢复 | 产品/安全 |
| OQ-11 | 整体冷静销毁由谁发起/批准，7 天到期如何执行和撤销？ | 只做明确标记的状态演示，不执行正式跨成员数据销毁 | 产品/服务端/法务 |
| OQ-12 | 仅自己可见能否重新共享？私人意象是否允许仅本人在 A 页看见？ | 不提供反向共享或私人 A 意象 | 产品 |
| OQ-13 | 援助资源覆盖地区、官方来源、验证周期、维护责任和失效降级是什么？ | Demo 仅安全分流与配置资源位；不硬编码未经核验号码 | 安全/产品 |
| OQ-14 | 音频切场景默认继续还是询问？跨刷新/设备是否恢复进度？ | 本次页面会话保留状态，切场景不自动新播；策略可配置 | 产品 |
| OQ-15 | API 分页、排序、筛选、时间格式、错误码和版本迁移契约是什么？ | Mock 采用统一 Repository 契约与 ISO 时间；适配器规范化 | 服务端 |
| OQ-16 | 正式视觉资产、字体、图标与参考图使用权如何确认？ | 仅使用获授权资源；无资源时采用中性占位层 | 视觉/法务 |
| OQ-17 | 首版纳入哪些 P1，P2 大陆入口展示还是隐藏？ | P0 先行，P2 不作为可用功能呈现 | 产品 |

## 检查结果与下一步所需输入

上述假设均可由配置或 Repository 适配器替换。下一步需产品、服务端、安全及视觉负责人对对应行作出决定并记录版本；未决行不得写成确定的正式业务规则。
