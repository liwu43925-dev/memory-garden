## 实施层级

1. HTML 交互层：导航、关系组切换、档案入口、表单、详情、抽屉、弹窗、唱片播放器、状态反馈、焦点管理。
2. SVG 图标层：统一 24px 线性图标，`currentColor`，不承载业务文案。
3. 场景数据层：花/叶/唱片等仅由已归档且已映射的记录生成；冷静期、已放弃、仅自己可见内容不能生成共享意象。
4. 插画资产层：背景、地面、树、房屋、桌宠、留声机等必须使用经批准的分层透明资产，不使用 CSS 几何形状冒充最终场景。

## 当前缺失资产与阻断结论

现有 6 张图片均为带 UI 和文字的扁平截图，没有可用于响应式裁切、点击命中、遮挡关系和数据驱动成长的独立图层。它们足以指导页面 B 的 HTML/CSS 视觉实现，但不足以把页面 A 的花园/老屋标记为视觉完成。当前应保留可运行的交互与数据闭环，并将页面 A 明确标为“分层插画待接入”，不得以几何树、纯色块或整图背景冒充完成。

所需最小资产包（桌面至少 2560px 宽，移动至少 960px 宽；透明元素按 2× 输出；无文字、无 UI、无阴影裁切）：

- 花园背景：天空、远山、围栏分层。
- 花园地面：石径、草地、花床分层。
- 心愿树：树干、主枝、树冠与可挂载点分层。
- 成长状态：花苞/初花/盛花、嫩叶/成熟叶、花瓣落下、叶片状态。
- 留声机、唱片与唱针（独立透明层）。
- 桌宠：静息、陪伴、倾听三种静态姿态；不自动动效。
- 老屋/庭院：墙体、窗、门、桌椅、茶具、花架、灯笼、围墙与院门分层。
- 纪念碑、心结幻影、记忆帷幕（P1，独立透明层）。
- 前景装饰：绣球、枝叶、散落花瓣及遮挡蒙版。
